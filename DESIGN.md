# X1 Quiz Show — Contest Design Direction

## 1. Objective

Design a distinctive, premium, interactive landing page for X1 Quiz Show.

This is a design-contest entry.

The goal is NOT merely to create a clean, competent, minimal website.

The goal is to create a landing page with enough visual authorship, interaction thinking, and memorable composition that it stands apart from other polished submissions.

The experience should immediately communicate:

X1 transforms a cinema audience into participants in a live interactive game.

The supplied X1 footage, interface, cinema environment, phone interaction, presenter, questions, rounds, and leaderboard are not simply content to display.

They are the raw material for the design language itself.

---

# 2. Creative Standard

The page must achieve all of the following:

- premium
- cinematic
- interactive
- modern
- editorial
- spatial
- emotionally engaging
- unmistakably related to X1

Minimalism does NOT mean simplicity of composition.

Minimalism means removing elements that do not contribute to the experience.

A composition may be large, layered, asymmetric, immersive, or technically ambitious while still being minimal.

Do not confuse:

clean with empty,
premium with conservative,
minimal with basic,
Apple-inspired with repetitive,
or AntiSlop with visually timid.

The page needs moments of visual surprise.

---

# 3. The Central Design Idea

The central concept is:

## THE AUDIENCE ENTERS THE SCREEN

X1 connects three spaces:

PHONE
→
AUDIENCE
→
CINEMA SCREEN

This relationship should influence the entire visual system.

The website should repeatedly demonstrate that actions originating from an individual audience member become part of a shared cinematic experience.

This concept is more important than conventional feature presentation.

Do not design a website that merely explains X1.

Make the website behave conceptually like X1.

---

# 4. Signature Visual Language

The design should use:

- cinematic scale
- dramatic cropping
- foreground/background relationships
- layered media
- controlled overlaps
- perspective
- depth
- masks
- framing
- asymmetric editorial layouts
- intentional motion
- transitions between personal and shared experiences

Media does not always need to live inside rectangles.

Video can:

- become the background
- extend beyond containers
- be masked by typography
- overlap section boundaries
- transition between compositions
- occupy most of the viewport
- sit behind foreground interface elements
- appear as the cinema screen itself

The page should have several screenshots that could only belong to this X1 experience.

---

# 5. AntiSlop Interpretation

All repository AntiSlop rules remain mandatory.

However:

AntiSlop is a filter against generic design patterns.

It is NOT an instruction to make the page conservative.

Avoid generic visual complexity.

Encourage concept-driven visual complexity.

BAD complexity:

- random floating shapes
- arbitrary glow
- decorative glass cards
- meaningless gradients
- generic tech grids
- floating dashboard widgets
- decorative particles
- random 3D objects
- fake UI
- excessive pills
- meaningless motion

GOOD complexity:

- cinema perspective
- X1 footage interacting with typography
- phone UI visually affecting the cinema experience
- layered audience/screen compositions
- quiz rounds transitioning like an actual show
- media moving through depth
- section transitions based on the X1 experience
- controlled visual overlap
- spatial storytelling

If an unusual composition reinforces the X1 concept, prefer it over the safer conventional layout.

---

# 6. Visual Identity

## Base

Near-black cinema environment.

Primary backgrounds:

#030303
#050505
#080808
#0C0C0C

Do not make every section exactly the same black.

Use extremely subtle tonal changes and media-derived darkness to create depth.

## Typography

Primary:
near-white.

Secondary:
muted warm/cool gray.

## Accent

Use the recognizable X1 electric blue derived from the supplied material.

Blue is a strong brand signal.

It may be used boldly at selected moments.

It must NOT become a generic neon glow effect.

Use it for:

- key words
- interaction states
- active quiz states
- selected answers
- navigation cues
- progress
- transitions
- brand moments

Large areas of blue are acceptable when compositionally justified.

---

# 7. Typography

Typography must feel designed, not merely formatted.

Use a strong modern grotesk/sans-serif.

Create tension between:

- very large display type
- small technical/interface labels
- restrained body copy
- media

Headlines may:

- span multiple lines
- interact with media
- sit partially behind visual elements
- align unusually
- change scale between sections
- become part of transitions

Do NOT repeat the same:

small eyebrow
+
large headline
+
paragraph

pattern throughout the page.

Do NOT center every headline.

Do NOT use identical typography scale in every section.

Typography should contribute to composition.

---

# 8. Page Rhythm

The visitor should experience alternating visual intensity.

Think in terms of:

QUIET
→
IMPACT
→
DISCOVERY
→
IMMERSION
→
ENERGY
→
RESOLUTION

Do not create six equally spaced marketing sections.

Some transitions may happen quickly.

Some experiences may occupy nearly a full viewport.

Some sections may visually merge into each other.

The scroll should feel directed.

Avoid excessive empty vertical space that exists only to create a premium appearance.

Whitespace should create tension, not emptiness.

---

# 9. Hero — Immediate Identity

The hero must remain one of the strongest screenshots in the entire submission.

It should communicate X1 within seconds.

Use supplied cinema footage as the environment, not merely as a background image.

Primary message direction:

THE CINEMA
BECOMES THE
GAME.

The composition should feel closer to a cinematic title sequence than a conventional website hero.

Possible techniques:

- foreground typography against moving cinema imagery
- selective masking
- large X1 branding
- footage emerging from darkness
- subtle depth between typography and video
- cinematic crop
- controlled camera-like motion

Keep CTA/navigation functional but visually secondary.

Do not cover the footage with unnecessary UI.

---

# 10. Transition From Watching to Playing

Immediately after the hero, establish the conceptual transformation:

WATCHING
→
PLAYING

Do NOT follow the hero with a generic explanatory section containing text beside a rectangular image.

Create a visual transition.

For example:

the cinema image from the hero may reduce, shift, crop, or transform while interaction/interface material enters the composition.

The visitor should feel that passive viewing is becoming participation.

Copy should remain short.

The composition carries the explanation.

---

# 11. Quiz Rounds — A Signature Section

This must NOT look like a standard carousel or feature gallery.

Treat this section as a miniature X1 show.

Use actual supplied round footage.

The dominant media area should feel like a cinema screen or broadcast stage.

Round navigation such as:

01
02
03

may exist, but it should feel integrated into the show identity rather than generic tabs.

Changing rounds should produce a meaningful visual transition.

Possible approaches:

- cinematic wipe
- mask transition
- screen replacement
- horizontal stage movement
- scale/depth transition
- broadcast-like cue transition

The selected round should alter the dominant visual state.

This section should clearly demonstrate interaction-design thinking.

---

# 12. Phone → Screen

This is one of the most important X1-specific concepts.

Do NOT settle for a conventional 50/50 split layout with a phone video on one side and text on the other.

Visually establish the relationship:

PERSONAL INPUT
→
SHARED RESULT

Use actual phone/interface footage.

The phone/interface may occupy the foreground.

Cinema or quiz footage may exist deeper in the composition.

Create a visual relationship between them.

Examples of conceptual treatment:

- phone interaction enters from foreground while the cinema screen responds behind it
- an answer state visually travels toward the large screen
- phone interface and cinema screen temporarily share one composition
- typography bridges the two spaces

This does not need to simulate a complete real quiz.

It needs to make the concept immediately understandable.

The section should produce one of the strongest screenshots on the page.

---

# 13. Competition

The competition section should increase energy.

Use supplied:

- presenter footage
- question footage
- leaderboard
- audience/game material

Do not present leaderboard footage as just another rectangular screenshot.

Treat ranking and competition as a visual event.

Possible composition:

- leaderboard occupying a large central plane
- presenter/question material layered around it
- rank typography entering the page
- large numbers becoming graphic elements
- controlled overlap between media states

The energy should increase without turning into gaming-site visual noise.

---

# 14. Spatial Composition

At least two major sections should use meaningful depth.

Depth can come from:

- overlapping media
- foreground UI
- background cinema footage
- scale differences
- perspective
- masks
- scroll movement
- typography crossing layers

Do not make the entire site a flat sequence of rectangles.

However, every layer must have a conceptual purpose.

---

# 15. Motion Direction

Motion is part of the design, not post-processing.

The site should include a small number of strong motion ideas.

Prioritize:

- continuity between sections
- media transformation
- mask reveals
- controlled scale
- depth movement
- active quiz transitions
- phone-to-screen relationship
- typography/media interaction

Use ordinary opacity/translate reveals only where they are sufficient.

Do NOT apply the same fade-up entrance to every element.

Avoid:

- bouncing
- random floating
- endless loops unrelated to media
- excessive springs
- cursor gimmicks
- scroll hijacking
- animation that slows navigation

Motion should reinforce cause and effect.

---

# 16. Navigation

Navigation should remain minimal.

X1 logo.

A small number of useful destinations.

One primary action if appropriate.

Navigation may initially exist over the hero and gain a subtle surface when required for readability.

Do not let navigation become a visual centerpiece.

All navigation interactions must work.

---

# 17. Media Rules

Use supplied X1 media as the dominant visual source.

Do not search for stock imagery unless absolutely necessary.

Do not use AI-generated imagery.

Video treatment:

- autoplay where appropriate
- muted
- loop
- playsInline
- no browser chrome
- no conventional player controls
- intentional cropping
- performance-aware loading

Do not show every supplied video simply because it exists.

Select footage based on the role it plays in the story.

Media should sometimes behave as environment rather than content.

---

# 18. Composition Diversity

Every major section should answer:

WHY IS THIS COMPOSITION APPROPRIATE FOR THIS IDEA?

Avoid repeatedly using:

TEXT | MEDIA

MEDIA | TEXT

TEXT | MEDIA

That alternating pattern is clean but generic.

Possible structures include:

- full viewport cinematic stage
- asymmetric overlap
- foreground/background composition
- sticky media with changing states
- large type crossing imagery
- media sequence
- controlled collage
- screen-within-environment
- horizontal progression
- layered depth

Do not use variety merely for novelty.

Use composition to communicate.

---

# 19. Apple Inspiration — Correct Interpretation

The client references Apple.

Do NOT interpret this as:

white space + giant font + centered product image.

Instead borrow Apple's principles:

- confidence
- visual hierarchy
- focus
- high-quality media
- purposeful motion
- product storytelling
- controlled complexity
- strong sequencing
- visual transitions
- disciplined typography

Apple pages often contain technically ambitious visual storytelling while appearing simple.

That is the target.

Simple perception.

Sophisticated composition.

---

# 20. Content

Existing/client-provided material is the source of truth.

Copy may be shortened, reorganized, or refined for presentation.

Do not invent:

- statistics
- customer counts
- testimonials
- awards
- partnerships
- pricing
- unsupported technical claims

Headlines can be expressive.

Supporting statements should remain conservative.

---

# 21. Footer Requirement

The footer must include:

Impressum
AGB
Widerrufsrecht
Über Uns
Datenschutz

These labels should be visible and usable.

The footer itself should remain visually restrained.

---

# 22. Interaction Requirement

The design should visibly demonstrate interaction thinking.

At minimum, the live implementation should communicate:

- navigation interaction
- smooth movement through the page
- interactive quiz/round state
- media transitions
- intentional hover states
- meaningful scroll behavior

Interaction should be apparent enough that a contest holder understands how the eventual Figma prototype would behave.

---

# 23. Desktop Priority

Primary design viewport:

1440px desktop.

This is a contest presentation first.

Desktop composition receives the highest visual priority.

Responsive behavior must remain functional, but do not simplify the desktop design merely to make mobile implementation easier.

---

# 24. What Must NOT Happen

Reject the implementation if it becomes:

- a generic black landing page
- a typography portfolio
- a sequence of large rectangular videos
- a clean but forgettable marketing website
- a SaaS page with X1 assets
- a gaming website full of neon
- a collection of unrelated animation tricks

Also reject it if the only reason it appears premium is:

large font
+
black background
+
lots of empty space.

That is not enough.

---

# 25. Mandatory Signature Moments

The page must contain at least THREE visually memorable moments:

### Signature 1
A cinematic hero where X1's identity is immediately unmistakable.

### Signature 2
A quiz-round interaction that feels like changing states inside an actual show rather than browsing website cards.

### Signature 3
A phone-to-cinema composition that visually communicates individual input becoming a shared screen experience.

At least one additional section should use meaningful layering/depth.

If these moments are absent, the design is not finished.

---

# 26. Contest Screenshot Test

Pause at several positions during the page.

Ask:

Would this still look distinctive as a static contest screenshot?

At least four different viewport positions should produce strong compositions.

If only the hero is memorable, the design is too weak.

If removing the X1 logo makes the page look like it could advertise any technology company, the design is too generic.

---

# 27. Final Principle

Do not decorate X1.

Do not merely arrange X1.

Stage X1.

The visitor should feel the transformation:

I am watching
→
I can participate
→
my action reaches the screen
→
the room becomes a game.

The final experience should feel like an interactive trailer for X1 itself.
